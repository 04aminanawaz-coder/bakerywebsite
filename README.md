## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/04aminanawaz-coder/bakerywebsite.git
```

Go to the project folder:

```bash
cd bakerywebsite
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 💡 About the Project

Rabia's Kitchen is a bakery website I created to practice and demonstrate my frontend development skills.

The project focuses on responsive design, reusable React components, navigation, animations, and creating a friendly and attractive user experience.
